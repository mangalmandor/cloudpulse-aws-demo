# CloudPulse — AWS Deployment Demo

A small responsive React dashboard made with Vite. It uses sample/demo metrics only; it does not connect to AWS or display live CloudWatch data.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```

## Create a production build
```bash
npm run build
```

Vite writes the production website to `dist/`. Upload the **contents** of `dist/` to an S3 bucket configured for static website hosting, or connect this GitHub repository to AWS Amplify. The `dist/` directory is included in this demo zip for quick preview, but normally it is generated by `npm run build` and is not committed to GitHub.

## Preview the production build
```bash
npm run preview
```

## GitHub push
```bash
git init
git add .
git commit -m "Add CloudPulse React AWS demo"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/cloudpulse-aws-demo.git
git push -u origin main
```

## AWS notes
- **S3:** upload the files inside `dist/`, not the source files.
- **AWS Amplify:** set build command to `npm run build` and output directory to `dist`.
- Replace demo data with real APIs before using it as a production monitoring dashboard.
